## Работа программы

Программа `overvalued_markets_parser.py` фильтрует события с негативным риском на Polymarket и выводит переоцененные, то есть те из них, сумма вероятностей исходов которых оценена рынком в более чем 100%. При этом скрипт считает не теоретическую сумму вероятностей, а сумму покупки позиции "No" на всех подрынках (по одному шейрсу) с учетом bestBid: эта сумма должна позволять сделать беспроигрышную ставку, скупив позиции "No".

В результате работы программа выводит список ссылок на переоцененные события и возможную выгоду от покупки позиций "No", выраженную в процентах годовых.

## Фильтры

Предустановлены следующие фильтры:
- `limit` = 100 и `offset` = 0 - определяют размер выборки и шаг пагинации. Шаг offset установлен равным 100. Пагинация происходит до `offset` = 1000.
- `negRisk`: `True`, `active`: `True` и `closed`: `False` - базовые фильтры, отсеивающие неактивные события и события без негативного риска.
- `order`: `liquidity` и `ascending`: `False` - позволяют рассматривать более ликвидные события в первую очередь.
- `exclude_tag_id`: 1 - отсеивает спортивные события.
- `end_date_max`: `max_date` - устанавливает максимальный срок заморозки капитала в событии. Этот срок определяется `timedelta(days=60)` и по умолчанию равен 60 дням.

Дополнительно в теле цикла происходит фильтрация по:
- `liquidityNum` - отсеиваются события с маркетами, имеющими ликвидность менее 1000$.
- `spread` - отсеиваются события с маркетами, имеющими спред более 3 центов.
- `bestBid` - отсеиваются события, в которых есть маркет, где bestBid для "Yes" менее 0.1 цента (минимальной цены шейрса). Купить позицию "No" на таком маркете не получится.
- В конце цикла условием `if apr >= 20:` установлен минимальный порог процента годовых.

## Запуск

Для запуска программы достаточно установить библиотеку `requests` и запустить парсер:

```bash
pip install -r requirements.txt
python overvalued_markets_parser.py
```
